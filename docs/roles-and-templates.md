# 账户分级、权限、过期与模板

## 级别

| 级别 | 来源 | 可做 | 可被谁撤 / 设过期 |
|---|---|---|---|
| 负责人 root（principal） | 只由 wrangler.toml `PRINCIPALS` 决定 | 全部；切换会话预设；查看审计；管理模板 | 不能在页面上授予、撤销、设过期 |
| 高级管理员（membership_lead） | root 授予 | 成员管理、给维护者授予 / 撤销、发邀请 | 只有 root |
| 维护者（inviter） | root 或高级管理员授予 | 发邀请、查看邀请 | 上级（root、高级管理员） |
| 普通账户 | 邀请注册 | 登录、管理自己的 passkey | — |

规则：不能自升级；不能授予与自己同级或更高的级别；同级不能互撤 / 互设过期；下级不能动上级。

## 权限覆盖（按账户）

`deny: ['invite.create']`：撤销某账户的发邀请权（并一并撤销其待使用的邀请），其他权限不变。root 的发邀请权不可撤；高级管理员的只有 root 能撤。

## 账户有效期 vs 会话时长

- **账户 / 角色有效期**：管理员设定。相对（如 1d、12h）或绝对时间；不带时区的输入按台北时间（UTC+8）解释，存储一律 UTC 毫秒，界面显示台北时间并标注时区。范围：未来且 ≤ 5 年。作用域 `account`（到期账户不能登录、已有会话 401）或 `role`（到期只摘掉角色，账户照常）。“永不过期”需先取消才能再设过期；PRINCIPALS 不能被设过期。
- **会话时长**：见 docs/session.md，与账户有效期独立；临时账户（设了过期的）落在“临时”档。

## 模板

模板只设定默认有效期与使用方式（访客、单次使用、OTP 次数），**不授予角色**。
