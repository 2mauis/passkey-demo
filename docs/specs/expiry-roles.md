# 账户 / 角色有效期、分级、权限覆盖、模板（无角色）、恢复禁用

## 背景/目标
临时成员需要自动到期；管理员分级需要明确谁能管谁；模板只设有效期。详见 docs/roles-and-templates.md。

## 非目标
任何创建或提升管理员的新入口；兜底恢复实现（docs/recovery.md，501）。

## 不变量
存储 UTC、显示台北时间；PRINCIPALS 不可设过期；同级不可互操作；模板不授予角色。
